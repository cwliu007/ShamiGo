蝦米GO 使用說明

蝦米GO是支援嘸蝦米字碼的跨平台輸入介面，並非官方嘸蝦米輸入法。使用前須備妥自己有合法使用權、檔名與格式相容的字根資料。

一、安裝、啟動與結束

系統 使用方式
Windows 解壓後執行 Run_Windows.cmd 可免安裝使用；Install_Windows.cmd 安裝；Uninstall_Windows.cmd 解除安裝。從通知區選單可開啟設定或結束程式。
macOS 解壓後執行 Install_macOS.command，也可複製 Install_macOS_Bash.txt 的整段指令至終端機；Uninstall_macOS.command 解除安裝。安裝後可從系統輸入來源選單切換。
Linux 解壓後執行 sh Install_Linux.sh 安裝；sh Uninstall_Linux.sh 解除安裝。輸入來源由 Fcitx5 管理。

二、輸入模式與快捷鍵

輸入模式包括 Eng、嘸、注音、拼音、快碼、簡體、日文。實際可用模式依各系統功能與已提供的字根而定。

Windows 預設群組 快捷鍵 模式
第一組 Ctrl + Space（或短按 Ctrl） Eng ↔ 嘸
第二組 Ctrl + Shift 注音 ↔ 拼音
第三組 Ctrl + Alt + Space 快碼 → 簡體 → 日文

這是出廠預設，可在設定中更改。Shift + Space 切換全形／半形；Ctrl + Alt + , 開啟快速符號選單。

macOS 差異：可按住 Fn 後連按 Space，或使用已啟用的自訂切換快捷鍵；Ctrl + Space 可能由 macOS 系統接管。Linux 差異：切換鍵以 Fcitx5 的輸入來源及快捷鍵設定為準。

注音與漢語拼音對照

注音與漢語拼音依國語讀音對照，不能將每個注音符號機械地換成一個英文字母。注音使用臺灣常見的大千鍵盤；拼音使用漢語拼音與數字聲調。

拼寫規則：ㄓ、ㄔ、ㄕ、ㄖ、ㄗ、ㄘ、ㄙ獨立成音節時寫作 zhi, chi, shi, ri, zi, ci, si；ㄩ在 j、q、x 後寫成 u，如 ju, qu, xu。複韻母會依音節簡寫，例如 ㄧㄡ→iu、ㄨㄟ→ui、ㄨㄣ→un（有聲母時）。

聲調：第一聲 1（陰平）、第二聲 2（ˊ）、第三聲 3（ˇ）、第四聲 4（ˋ）、輕聲 5（˙）。例如 ma1 至 ma5 分別對應 ㄇㄚ、ㄇㄚˊ、ㄇㄚˇ、ㄇㄚˋ、ㄇㄚ˙。

三、輸入、候選與英文輸出

  • 中文字碼輸入後，Space 選第一候選（第 0 個），V / R / S / F / W / L / C / B / K 可選後續候選；亦可用候選編號或滑鼠點選。若按鍵仍能組成有效字碼，會優先繼續組字。
  • PageUp / PageDown 翻候選頁。Windows 浮動框上的滑鼠滾輪向上到下一頁、向下到上一頁，每次一頁；其他系統以其候選介面為準。
  • 在中文模式下，輸入英文單字後按 Space 會輸出英文及一個半形空格；按 Tab 或 Enter 只輸出英文，不附加空格。Tab 也可直接送出尚未確認的原始字碼。
  • 英文拼字候選來源及排序不變，英漢詞義僅使用離線內建的 ECDICT 英漢雙解詞典。每頁最多五個候選字。
  • Windows：將滑鼠停在英文拼字建議候選字上，可查看本機字典的音標、英義、臺灣繁中解釋及例句。泡泡框最多顯示 10 行，超過可捲動；未收錄的單字會明確提示。
  • 已輸出的英文按 Backspace 或 Delete 會逐字刪除；拼字建議中的錯誤英文碼按 Backspace 可退一碼，重打後按 Space 會重新檢查。
  • Eng 英文模式提供拼字檢查；判定使用原本的候選索引與內建 ECDICT 詞條，不會直接改字。
  • 英文拼字候選來源及排序不變，英漢詞義僅使用離線內建的 ECDICT 英漢雙解詞典。每頁最多五個候選字。
  • 錯誤字碼：沒有有效候選時，浮動框會顯示錯碼提示；英文拼字建議可按 Backspace 修改最後一碼，再確認；Delete 清空未確認的英文碼。開啟「錯碼推薦」後，才會額外顯示可能的修正候選。

四、浮動框與設定

  • 狀態框及模式切換提示預設 1 秒；選字後結果提示預設 2.5 秒（以該平台有提供的提示類型為準）。正在輸入的候選框不會因狀態提示到期而消失。
  • Windows 的秒數欄位可輸入小數，例如 2.5、0.75，並依毫秒精度儲存。
  • 預設跟隨文字游標顯示浮動框；可依系統支援情形調整位置、字型大小、透明度、外觀與固定方式。固定浮動框或滑鼠停留保留等功能可能延長顯示。
  • 關聯詞、罕見字及錯碼推薦預設關閉；需要時可自行開啟。可在設定中調整選字提示、字型及顯示秒數。
  • Windows 支援成對符號補齊及巢狀 Tab 跳出；macOS 不使用這套自動配對功能。Linux 的支援依目前 Fcitx5 輸入模式而定。
  • 「查字」可反查字碼、同音字及相關候選，查詢不會自動取代原文件文字。

五、字根與個人資料

三個系統各自使用獨立的 LicensedTables 資料夾，請放入合法取得且符合程式要求的字根檔：

系統 ZIP 內放置位置
Windows Packages/Windows/ShamiGo/LicensedTables/
macOS Packages/macOS/LicensedTables/
Linux Packages/Linux/LicensedTables/

Mac 安裝時會把字根放到 ~/Library/Application Support/ShamiGo/LicensedTables/，不放入已簽署的 App。安裝完成後的私人離線安裝包在 Packages/macOS/Private_Builds/，其中 App 與字根資料夾分開。修改字根後，請完整結束並重新啟動輸入法。自訂詞組可使用 liu.box，請自行備份。
