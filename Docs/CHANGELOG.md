# 蝦米GO目前版本與變更摘要

## 封裝 v0.10.395（2026-10-30）

- **僅交付一份個人完整版 ZIP**，保留原始碼、C++ 專案、私人授權字根與全部執行工具。
- 修正 GitHub 發布流程誤將私人版 README 複製到公開版的問題：公開版統一使用獨立、經檢查的使用者說明模板。
- 修正授權文件的相對連結，增加公開版 README 連結與私人內容的測試，並檢查封裝版本及執行檔版本差異。
- GitHub 更新時才在暫存目錄移除原始碼與字根，重建 CMD 及 VM 內嵌內容。**不製作另一份公開版 ZIP**。
- **Windows 主程式仍為 v0.10.394，Linux 套件仍為 v0.10.366-1**；沒有更動已驗證的 EXE 或 DEB。



## Windows v0.10.394（2026-10-28）

- 主程式與兩個管理員輔助 EXE 以 v394 發行，輸入核心與 v391 相同。原 v394 修正 ZIP 單一 CMD 執行時的舊版目錄白名單、部分解壓處理及 UAC 安裝／移除診斷。
- 本次維護只調整文件、專案資料歸檔及 Github 上傳的安全過濾程序，**沒有重編主程式或宣稱新增輸入功能**。
- **僅交付一份個人完整版 ZIP**。日後僅在作者明確要求發布 GitHub 時，產生經核對的暫存目錄、上傳後清除；不另製作公開版壓縮檔。
- 近期既有功能：預設淺色介面、70% 浮動框不透明度、2 秒結果提示、成對符號補齊、浮動框透明穿透與位置設定、候選與注音等。詳細現行行為請以 v394 `ShamiGo_Help.html` 和 `ShamiGoCPP.ini` 為準。

## Linux v0.10.366-1

- Debian 13 / LMDE 7 使用 Fcitx5 `.deb`，包含候選顯示及部分多模式功能；與 Windows 平台尚不完全一致。
- 仍沿用 v366 的既有執行檔；私人字根需另外匯入。GitHub 公開版之 VM 傳輸 TAR 只攜帶 `.deb`，不攜帶任何受版權保護的字根。

## 測試界線

驗證涵蓋原始碼邊界、SHA-256、封裝目錄、嵌入式 CMD 完整性、Linux 套件、Windows 回歸測試，以及不含私有字根的公開版檢查。未在 Windows 11 實機測試 UAC/Explorer/VirtualBox，也不代表所有 Linux 桌面環境已通過最終驗收。
