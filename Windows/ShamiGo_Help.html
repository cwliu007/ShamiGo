蝦米GO 使用說明

蝦米GO是嘸蝦米輸入法的免安裝外殼。 沿用自己合法取得的嘸蝦米字根資料，Windows 版不需要安裝即可直接啟動，也能選擇安裝並設定登入後自動啟動。

建議先使用免安裝方式：放入 liu-uni.tab，再雙擊 Run_Windows.cmd 即可。

一、免安裝直接使用（建議）

  1. 從 GitHub 下載完整資料夾，解壓縮後保留原本的資料夾結構。
  2. 將自己合法取得的嘸蝦米字根檔 liu-uni.tab 放入 Windows/LicensedTables/。
  3. 雙擊根目錄的 Run_Windows.cmd，直接啟動蝦米GO。
  4. 不使用時，可在 Windows 通知區的蝦米GO圖示按右鍵，選擇結束程式。

免安裝版不需要先執行 Install_Windows.cmd，也不會建立登入後自動啟動的工作排程。 只要保留整個資料夾，就可以再次執行。

蝦米GO是嘸蝦米輸入方式的輔助外殼，不提供嘸蝦米的專有字根表；首次進行字根輸入前，必須自行準備具有使用權的字根檔。

二、安裝、自動啟動與移除（選用）

若希望每次登入 Windows 都能自動使用蝦米GO，可以執行根目錄的 Install_Windows.cmd。程式會要求一次 Windows 管理員授權，將蝦米GO安裝到受保護的資料夾，並建立登入後自動啟動的工作排程。

檔案用途
Run_Windows.cmd免安裝直接啟動，不設定自動啟動。
Install_Windows.cmd安裝程式，並設定 Windows 登入後自動啟動。
Uninstall_Windows.cmd移除已安裝的蝦米GO及其工作排程；不會刪除原本下載的免安裝資料夾。

移除安裝版前，請先從通知區結束蝦米GO，再執行 Uninstall_Windows.cmd。個人設定和字根資料請自行保留備份。

三、輸入模式

主要用途是透過使用者自己的嘸蝦米字根資料輸入繁體中文，並提供下列輔助模式：

模式功能
嘸蝦米中文使用既有嘸蝦米字根表輸入漢字，可搭配候選字、同音查字及自訂字碼。
英文一般英文字母、數字及符號輸入。
注音以臺灣常用的大千注音鍵盤輸入並選字。
拼音輸入漢語拼音及聲調，例如 shi4。
快碼顯示較短的字根輸入提示，協助熟悉字根。
簡體中文使用相應字根資料輸入簡體字。
日文提供日文假名及相關輸入方式。

部分模式需要額外的合法字根資料。可從蝦米GO的模式選單切換。

四、候選字與快捷鍵

操作功能
Ctrl + Space切換主要的英文／中文輸入模式；也可在設定中調整配對。
Ctrl + Shift切換第二組輸入模式，預設為注音／拼音。
Ctrl + Alt + Space切換第三組輸入模式，預設為快碼／簡體／日文。
Shift + Space切換全形及半形。
Space在可選字狀態下選取第一個候選字。
V、R、S、F、W、L、C、B、K依序選取後續候選字；若按鍵仍可構成有效字根，會優先保留字根輸入。
PageUp／PageDown切換上一頁／下一頁候選字。

候選字通常以 0～9 顯示，請依目前畫面選字。滑鼠放在候選框上時，滾輪往上是下一頁，往下是上一頁。注音及拼音在聲調尚未確定時，部分數字鍵仍用來組音；請以目前候選狀態為準。

如果使用滑鼠滾輪捲動候選字，數字等快捷選字鍵可能暫時停用；可以用滑鼠點選，或按 PageUp／PageDown 回到明確的分頁選字狀態。

五、標點與成對符號

蝦米GO支援括號、引號等成對符號。沒有選取文字時，游標可停留在符號中間；先選取文字再輸入成對符號時，部分編輯器也能將原文字包覆起來。

對於剛輸入的空括號或空引號，可使用 Backspace 刪除整對。輸入成對符號內的文字後，視編輯器與游標狀態，可使用 Tab 跳到右側結尾符號。

按 Ctrl + Alt + , 可開啟特殊符號候選。實際操作會配合當前輸入模式與文字編輯器。

六、浮動框與設定

雙擊 Windows 通知區的蝦米GO圖示，或使用右鍵選單開啟設定。可以調整輸入模式配對、候選字數量、字體大小、淺色／深色外觀、浮動框位置、透明度及顯示時間。

也可以使用關聯詞、注音與拼音提示、罕見字和錯碼推薦等輔助功能。個人設定與自訂字碼可儲存在使用者的設定檔或 liu.box 中，變更或移動資料夾前建議先備份。

七、遠端控制

使用 RustDesk、TeamViewer、AnyDesk、Windows 遠端桌面等軟體時，蝦米GO可依遠端控制視窗的狀態調整按鍵處理，減少本機與遠端電腦同時攔截輸入的情況。

如有特殊遠端軟體，可從設定中的「指定遠端程式」選取。能否完整傳送所有快捷鍵，仍取決於遠端軟體及視窗環境。

八、常見問題

問題處理方式
能不能不安裝就直接使用？可以。 放好自己的 liu-uni.tab 後，雙擊 Run_Windows.cmd 即可。
字根輸入沒有候選字確認 Windows/LicensedTables/liu-uni.tab 存在，並確認目前是嘸蝦米中文模式。
想要登入後自動啟動執行 Install_Windows.cmd，依照 Windows 提示完成安裝。
要移除安裝版先結束程式，再執行 Uninstall_Windows.cmd；免安裝資料夾仍會保留。
注音／拼音無法使用數字選字請確認聲調是否已選定；若正在滾動候選字，可改用滑鼠或分頁鍵。
特定軟體無法使用部分按鍵檢查輸入模式、軟體權限，以及該軟體是否攔截相同快捷鍵。

九、字根與資料來源

蝦米GO不提供嘸蝦米專有字根表，使用者應自行合法取得並依原授權條件使用。蝦米GO是非官方的免安裝輸入外殼，並非嘸蝦米官方產品。

注音與拼音參考資料來源包含小麥注音（McBopomofo）；部分詞組資料來源為萌典相關整理。第三方資料來源及授權文字請參閱 第三方資料來源與權利聲明。
